# AWS VPC Peering Project

## Project objective
Build and test private connectivity between two Amazon VPCs using VPC Peering.

## Learning goals
- Understand VPCs, CIDR blocks and subnets.
- Configure route tables and security groups.
- Connect to private EC2 instances through a bastion host.
- Test connectivity before and after VPC Peering.
- Document test results and clean up AWS resources.

## Environment
- Operating system: Windows
- SSH client: OpenSSH for Windows
- Version control: Git
- Editor: Visual Studio Code
- Cloud platform: Amazon Web Services

## Project status
Phase 1: Local tools verified; documentation workspace being prepared.
